# 模拟会话

基于 md 文件的问答系统。用户登录后提问，每个问题生成一个自增编号的 md（`1.md`、`2.md`、`3.md`…），
系统监控该用户编号最大的 md，一旦里面出现 **回答完毕**，就把回答部分返回给这个用户。

只依赖 Python 标准库（Python 3.9+），不用装任何包。

## 启动

双击 `start.bat`，或：

```bash
python app.py
```

浏览器打开 http://127.0.0.1:8000

首次启动会自动创建管理员 **admin / admin123**，第一次登录会强制修改密码。

常用参数：

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `--host` | 监听地址，局域网其他电脑要访问就用 `0.0.0.0` | `127.0.0.1` |
| `--port` | 端口 | `8000` |
| `--default-dir` | 新建用户时默认的 md 目录 | `C:\Users\23695\Documents\longlingl` |
| `--db` | 数据库文件 | `data\app.db` |
| `--admin-password` | 首次启动时管理员 admin 的密码 | `admin123` |

## 功能

- **账号密码登录**：密码用 PBKDF2 加盐哈希保存，登录有效期 7 天。
- **管理员管理用户**（顶部「用户管理」）：新建、编辑、删除、启用或禁用用户，重置密码，设置角色，以及
  **为每个用户单独配置 md 目录**。目录不存在会自动创建。
- **提问**：在用户自己的 md 目录里生成下一个编号的 md，编号 = 目录里现有 `数字.md` 的最大值 + 1。
  多个用户可以共用同一个目录，编号不会冲突。
- **监控与返回**：每个用户同一时间只有一个待回答问题，也就是他编号最大的那个 md。后台每秒检查一次，
  出现“回答完毕”就把回答部分推送到页面上（长轮询，几乎实时）。等不到的话可以点「取消等待」，然后继续提问。

## md 文件格式（回答方需要遵守）

系统生成的文件：

```
问题：今天天气怎么样

回答：

```

回答方在 `回答：` 下面写回答，**写完后另起一行写上 `回答完毕`**：

```
问题：今天天气怎么样

回答：

晴，25 度，适合出门。

回答完毕
```

返回给用户的内容是 `回答：` 和最后一个 `回答完毕` 之间的文字。
- `**回答完毕**`、`【回答完毕】` 这类写法也能识别。结尾多出来的 `---` 分隔线会被去掉。
- 文件最后一次修改后要静止 1 秒才会读取，避免读到写了一半的内容。
- 文件用 UTF-8 读取，读不了时按 GBK 读。

## 接口（给脚本用）

所有接口都是 JSON，登录后靠 Cookie `sid` 鉴权。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/login` | `{"username","password"}` |
| POST | `/api/questions` | `{"question"}`，生成 md，返回问题信息（含 `id`、`md_path`） |
| GET | `/api/questions/{id}?wait=60` | 查询结果；`wait` 表示最多等多少秒，回答完毕立即返回，`status` 为 `answered` 时 `answer` 就是回答 |
| GET | `/api/questions` | 自己最近 200 条问答 |
| POST | `/api/questions/{id}/cancel` | 取消等待 |

例子：

```bash
curl -c c.txt -H "Content-Type: application/json" -d "{\"username\":\"admin\",\"password\":\"你的密码\"}" http://127.0.0.1:8000/api/login
```

## 文件

- `app.py`：后端，包括 HTTP 服务、SQLite、md 监控线程
- `static/index.html`：前端页面
- `data/app.db`：数据库，首次运行时自动生成。删掉它就会恢复到初始状态（md 文件不受影响）
